# サンプル工務店 相談予約アプリ

サンプル工務店の社長が、AIに頼んで作った、相談の予約を受け付けるアプリです。お客さんは、アカウントを作ってログインし、氏名、電話番号、住所、相談内容を入れて予約します。自分の予約は、後から見られます。社員は、管理画面ですべての予約を見て、一覧をCSVで書き出せます。アプリはVercelで公開し、データはSupabaseに保存しています。作ったのは社長で、ほかに面倒を見ている人はいません。

## このリポジトリについてのお断り

- これは、セキュリティの点検を練習するための、架空のアプリです。演習では、上に書いたとおり、公開されて動いているアプリとして扱ってください。
- 動いている環境を用意していない場合は、点検の途中で、AIからアプリを公開しているかを聞かれたら、「演習の設定では公開しています。動いている環境や公開のURLは手元にありません」と答えてください。
- 点検の途中で、AIからコードの置き場所を聞かれたら、「演習の設定では、GitHubに非公開で置いています」と答えてください。
- このリポジトリのコードは、読んで点検するためのものです。実際に公開したり、実在の人のデータにつないだりしないでください。
- Vercel、Supabase、GitHubの管理画面を用意していない場合は、点検の途中で画面を開くよう求められたら、「見られない」と答えてください。
